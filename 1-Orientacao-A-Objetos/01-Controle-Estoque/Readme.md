# Exercícios de Orientação a Objetos

### 📦 01 - Controle de Estoque (`01-Controle-De-Estoque`)
* **Problema:** Fazer um programa para ler os dados de um produto em estoque (nome, preço e quantidade). Em seguida, permitir adicionar e remover unidades do estoque e mostrar os dados atualizados.
* **Conceitos aplicados:** Encapsulamento simples, palavra `this`, métodos `void` e sobrescrita do `toString()`.
