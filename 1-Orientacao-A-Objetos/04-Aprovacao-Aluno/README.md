# 04 - Aprovação de Aluno

Programa para ler as três notas de um aluno, calcular sua nota final e informar se ele foi aprovado ou reprovado. Caso reprovado, exibe quantos pontos faltaram para atingir o mínimo (60.0).

### Conceitos aplicados:
* Orientação a Objetos (atributos e métodos)
* Estruturas condicionais (`if / else`) para regra de negócio
* Encapsulamento de cálculo de pendência com `missing()`
