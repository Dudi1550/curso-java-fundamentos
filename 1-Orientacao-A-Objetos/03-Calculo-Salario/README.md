# 03 - Cálculo de Salário de Funcionário

Programa para ler os dados de um funcionário (nome, salário bruto e imposto), mostrar o salário líquido e atualizar o salário com base em uma porcentagem informada.

### Conceitos aplicados:
* Orientação a Objetos (atributos, métodos com parâmetros e métodos sem retorno `void`)
* Atualização do estado do objeto com operador de atribuição cumulativa (`+=`)
* Formatação de saída e reuso de lógica com `netSalary()` no `toString()`
