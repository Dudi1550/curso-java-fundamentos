# Orientação a Objetos - Exercícios

Nesta pasta estão armazenados os exercícios de fixação sobre Programação Orientada a Objetos (POO) em Java.

### Tópicos praticados:
* Classes, Atributos e Métodos
* Sobrecarga e palavra `this`
* Sobrescrita do método `toString()` (Herança da classe `Object`)
* Métodos com e sem retorno (`void`)
