# 05 - Membros Estáticos e Classe Utilitária (Calculadora)

Exercício prático focado na aplicação de membros estáticos (`static`) em Java para a criação de uma classe utilitária de cálculos geométricos.

## Conceitos Praticados
* **Membros Estáticos (`static`):** Criação de métodos e constantes que pertencem à classe e não ao objeto instanciado.
* **Classe Utilitária:** Encapsulamento de funções matemáticas puras sem a necessidade de instanciação via operador `new`.
* **Constantes (`final`):** Uso do modificador `final` para definir o valor imutável do PI (`3.14159`).
