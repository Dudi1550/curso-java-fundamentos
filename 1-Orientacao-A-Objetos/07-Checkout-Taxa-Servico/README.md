# 07 - Cálculo de Checkout e Taxas (Membros Estáticos)

Exercício prático focado em criar uma classe utilitária para calcular o valor total de uma compra com acréscimo de taxa de serviço e imposto fixos.

##  Conceitos Praticados
* **Membros Estáticos (`static`):** Criação de métodos utilitários sem necessidade de instanciar a classe.
* **Constantes (`final`):** Definição da taxa de serviço (`SERVICE_FEE = 5`) e do imposto (`TAX = 8`) como constantes imutáveis.
* **Boas Práticas de Nomeação:** Uso de variáveis expressivas (`taxAmount`, `unitPrice`, `quantity`).
