# 06 - Conversor de Moeda (Membros Estáticos)

Exercício de fixação focado em criar um utilitário para conversão de dólar para real aplicando taxa fixa de IOF (6%).

##  Conceitos Praticados
* **Membros Estáticos (`static`):** Métodos e constantes utilitárias que pertencem à classe.
* **Constante (`final`):** Definição da taxa de IOF como valor imutável (`IOF = 6.0`).
* **Estrutura de Pacotes:** Separação clara em pacotes `.util` para utilitários e `.application` para a classe principal.
